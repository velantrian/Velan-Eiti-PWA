# ⚡ Velan Eiti PWA

🚀 **Progressive Web App** для работы с AI чатами и агентами в офлайн-режиме через Ollama

---

## ✨ Возможности

💬 **Умный чат**
- Множественные чаты с историей
- Поддержка Ollama (офлайн)
- Поддержка внешних API (OpenAI, DeepSeek и др.)
- Озвучивание сообщений (Web TTS)
- Копирование текста в один клик

🤖 **AI Агенты**
- Автономные агенты для задач
- Загрузка файлов для контекста
- История работы агентов
- Управление файлами

📎 **Умная работа с файлами**
- Система чанков для больших файлов
- Автоматический поиск релевантных частей
- Поддержка множества форматов
- Перекрытие чанков для контекста

🎨 **Красивый интерфейс**
- Темная и светлая темы
- Стеклянный эффект (Glassmorphism)
- Адаптивный дизайн
- Полноэкранный режим (двойной тап)

💾 **Сохранение данных**
- IndexedDB для локального хранения
- История сообщений
- Настройки конфигурации
- Резервные копии агентов
